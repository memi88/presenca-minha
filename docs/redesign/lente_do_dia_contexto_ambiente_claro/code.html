"A atenção é a forma mais rara e pura de generosidade."

— Simone Weil

A reflexão de hoje nos convida a observar como distribuímos nossa presença. Em um mundo de distrações fragmentadas, escolher onde colocar nossa atenção torna-se um ato de doação profunda.

Este conceito, enraizado na filosofia contemplativa do século XX, sugere que olhar verdadeiramente para o outro, ou para o momento presente, exige esvaziar-se temporariamente das próprias urgências. É um exercício diário de retorno.
